Ключи API

Gemini. Квоты Google считаются на проект и на модель, а не на ключ: ключи из одного проекта делят общий лимит, ротация помогает только между разными проектами AI Studio.
Числа RPM / TPM / RPD смотрите в AI Studio для каждого проекта: правила квот Google. Наличие бесплатного тарифа у модели не гарантирует доступ этому проекту. Ответ API с limit: 0 означает нулевую квоту, а не превышение RPM.
OpenAI. Бесплатные токены в день (250 тыс. для gpt-5.x / 4.1 / 4o / o1 / o3 и 2,5 млн для mini и nano) действуют только при включённом в настройках организации share traffic with OpenAI; лимит считается на организацию, а не на ключ.
Уже добавленные ключи не продублируются.

OpenAI: потребление организации за сегодня
Счётчики выше видят только запросы этого инстанса. Бесплатный лимит OpenAI общий на организацию и сбрасывается в 00:00 UTC, поэтому счёт ведёт общая библиотека openai_budget (одна на все проекты на этой машине): перед каждым запросом она проверяет, влезет ли он в лимит с запасом, и не пускает лишнее. Точные цифры берутся из отчёта OpenAI — для него нужен Admin-ключ (platform.openai.com → Settings → Organization → Admin keys); он только читает статистику и хранится в ~/.openai_budget/config.json.
